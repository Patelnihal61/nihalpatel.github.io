# Nihal Patel – Portfolio

Personal portfolio of Nihal Patel, Web / Full-Stack Developer (WordPress, PHP, WooCommerce) and M.Sc. Industrial AI student in Germany.

Live site: `https://patelnihal61.github.io/nihalpatel.github.io/`

## Files
- `index.html` – the whole site (no build step, no dependencies)
- `assets/photo.png` – profile photo
- `assets/Nihal_Patel_CV.docx` – downloadable CV

## Publish on GitHub Pages
1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save.
4. Your site appears at `https://YOUR-USERNAME.github.io` within a few minutes.

## Update later
- Add live project links in the *Selected work* section of `index.html`.
- Replace the CV in `assets/` when you update it, keeping the same file name.
